# Python 2FA System with MySQL

## Setup
1. Install dependencies: `pip install -r requirements.txt`
2. Set up MySQL database as described.
3. Update config.py with your email credentials.
4. Run: `python app.py`

## Features
- Registration with email uniqueness check.
- Login with OTP email verification.
- Creative login page with registration link.
- Dashboard after successful login.

## Testing
- Register a user.
- Login and check email for OTP.
- Verify OTP and access dashboard.
